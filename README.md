# The Mo Zone

Team RISE Builder's Playbook. A 13 slide training deck on the 30 minutes
before and after an event, and how a guest gets owned from the door to the car.

**Present it:** open the live link, then press `F` for full screen.

| Key | Does |
|---|---|
| `→` `space` `click` | Next slide |
| `←` or click the left edge | Previous slide |
| `F` | Full screen |
| `Home` / `End` | First / last slide |

Single self-contained HTML file. No build step, no assets, no internet needed
once the page has loaded.
